# Da Vinci game simulator

An agentically developed Unity simulator project. The repository is currently in governance/bootstrap phase; no new game implementation is introduced by the initial setup.

Start with [project intent](docs/PROJECT_INTENT.md), then read [AGENTS.md](AGENTS.md) and the [documentation index](docs/README.md).

## Clone

```bash
git clone --recurse-submodules <repository-url>
```

For an existing clone:

```bash
git submodule update --init --recursive
```
