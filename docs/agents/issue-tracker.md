# Issue tracker configuration

- Tracker: GitHub Issues and Pull Requests in the repository origin.
- Issues capture actionable outcomes and evidence; creating or claiming an issue is optional.
- Inspect relevant issues and PRs when starting or integrating work. Remote issue changes require task authorization.
- `docs/coordination/ACTIVE_WORK.md` is a historical snapshot, not a required ownership registry.
- Current integration rules: `docs/workflows/GIT_WORKFLOW.md`.
