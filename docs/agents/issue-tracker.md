# Issue tracker configuration

- **Tracker:** GitHub Issues and Pull Requests
- **Repository:** the GitHub repository configured as `origin` (intended: `Cadastrophi/davinci-game-sim`)
- **Unit of work:** one issue linked to one feature branch and one pull request
- **Coordination:** issue claims and PR state are authoritative; `docs/coordination/ACTIVE_WORK.md` mirrors active ownership

Agents must inspect open issues and PRs before starting, pushing, or merging. Create or modify remote issues/comments only when the user has authorized that external action.
