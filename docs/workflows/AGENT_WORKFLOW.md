# Agent workflow

1. Recover intent from AGENTS.md, CONTEXT.md, PROJECT_INTENT.md, relevant ADRs and issue/PR history.
2. Append non-trivial requests, scope, assumptions and acceptance criteria to the intent log.
3. Follow [Git workflow](GIT_WORKFLOW.md) for a unique local feature branch, implementation, validation, review and integration.
4. Document actual behavior and evidence with the change. Keep product decisions explicit; follow TDD at confirmed public interfaces for behavioral corrections.
5. Record the final SHA, checks, limitations and next safe action in the PR or handoff.

There is no concurrent-device, peer-handshake, sole-merger or hackathon deadline requirement. Inspect actual overlap when it occurs. Historical launch records preserve what happened but do not impose current operating rules.
