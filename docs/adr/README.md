# Architectural decision records

Create an ADR for decisions that constrain future implementation, affect multiple subsystems, or would be costly to rediscover.

Naming: `NNNN-short-title.md`. Status values: `proposed`, `accepted`, `superseded`, or `rejected`.

## Template

```markdown
# NNNN — Decision title

- Status: proposed
- Date: YYYY-MM-DD
- Owners: human / agent

## Context

## Decision

## Consequences

## Alternatives considered

## Follow-up
```
